# Nothing Keyboard 视觉与交互规范

## 1. 设计目标

键盘首先是高频工具，视觉风格不得牺牲输入准确率。整体使用纯黑背景、清晰白字和单一红色强调，避免渐变、发光和持续循环动画。

## 2. 色彩

- 键盘背景：`#000000`
- 工具栏背景：`#050505`
- 普通键：`#0D0D0D`
- 功能键：`#171717`
- 主文字：`#F2F2F2`
- 次文字：`#8A8A8A`
- 强调色：`#EB3036`
- 强调色仅用于回车、当前状态、候选序号和短促按压反馈。

同一屏内不增加第二种高饱和点缀色。红色面积应明显小于黑白灰面积。

## 3. 字体

- 中文候选、按键汉字：系统无衬线字体，优先保证清晰和字重稳定。
- 英文字母键、数字键、副字符与紧凑功能标签使用 Doto Bold，并保留轻微字距。
- 空格键上的语言名称使用 Doto；字体缺失字形时必须由 Android 系统字体回退，不显示方框。
- 不强行把点阵字体应用到中文，也不通过低分辨率位图模拟字体。
- 主要字符必须在真机正常观看距离下可一眼识别。

## 4. 布局

- 键位网格必须等宽、等高、等间距；任何动画不得改变键位几何位置。
- 顶部候选区与主键盘必须有明确分层，但左右内容边界保持一致。
- 回车、退格、Shift 等功能键保持一致的视觉权重。
- 圆角使用统一半径体系；小键不单独引入过大的胶囊圆角。
- 适配 3120×1440 屏幕时以 dp 和可触达尺寸为准，不按像素硬编码。
- Nothing 主题保留经典 QWERTY 键盘的原始键位比例：字母键、Shift、退格、空格和回车可根据功能使用不同宽度，不强制裁成正方形。
- 主字符按可见键帽的几何中心对齐；透明触控区不得小于 `48dp × 48dp`。
- 副字符位于主字母正上方居中，不能放在右上角，也不能与主字母或相邻行重叠。
- 候选首项的红色标记与候选文字使用固定间距，不能随候选字数或测量宽度漂移。
- 同一行的键帽上下边界必须一致，功能键可以更宽，但不得因造型破坏整行基线或越出键盘安全区。

## 5. 快捷工具栏

首批入口建议为：剪贴板、光标控制、数字行开关、常用短语、主题切换。默认只显示 4–5 个高频入口，更多功能放进二级面板。

工具栏展开和收起应使用 160–220 ms 的位移加淡入，支持中途反向；展开时不应令输入区域突然跳动。Dotboard 仅作为交互观察样本，代码与素材不进入本项目。

## 6. 动效

- 按压反馈：80–120 ms，轻微红色水波纹或亮度变化。
- 面板切换：160–220 ms，使用减速曲线。
- 状态切换：只动画变化的图标和标签，不带动相邻元素。
- 禁止持续闪烁、长时间弹跳和导致字符模糊的缩放动画。
- 动效应可关闭，并遵循系统“移除动画”设置。
- Nothing 点阵只用于克制的状态和品牌细节：首选候选标记使用 `1 × 4` 红色点阵，空格键文字下方使用一条静态五点阵基线。
- 按键反馈不叠加角落点阵，避免在快速输入时产生零碎闪烁。
- 点阵不得覆盖主字符，不得在整个键盘上常驻闪烁，也不用来替代需要高清晰度的中文候选字。

## 6.1 滑动输入

- 字母键向上滑动直接输入其顶部数字或符号；长按仍可保留扩展字符面板，但不作为快速输入的唯一方式。
- 删除键左右滑继续用于选区删除；上滑清空当前输入框，下滑撤回上一步。
- 清空全部属于高影响操作，必须使用比普通副字符上滑更长的阈值，并在触发时提供一次明确触觉反馈。
- 垂直删除手势与水平选区手势按主方向互斥，不能在一次手势中同时执行。

## 7. 性能与隐私

- 连续滑动、快速输入时保持稳定帧率，输入线程不得承担复杂绘制。
- 不为装饰效果持续高频刷新整块键盘。
- 不接入不必要的联网、统计或广告 SDK。
- 任何云端输入、同步或词库下载功能必须显式说明并可关闭。

## 8. 验收基线

- 中文、英文、数字和符号页面均无低对比度文字。
- 竖屏常用应用中不遮挡输入框；横屏和分屏不出现裁切。
- 长按弹窗、候选栏、剪贴板和设置页颜色一致且文字清晰。
- 快速连击不丢键、不出现键位跳动或残影。
- 可在系统设置中一键切回原输入法，卸载后不留下系统级修改。
